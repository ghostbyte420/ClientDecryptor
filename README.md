## ClientDecryptor </br>
```This Utility Removes Encryption From Official Ultima Online™ Game Clients```</br>

---
This is a small utility that is needed if users are running an Ultima Online™ game emulator and they wish to use an official client, instead of a 
custom one like Orion, ClassicUO, or CrossUO. This software will remove the encryption off all official clients (past and present).
